# ST Servo Driver for ESP-IDF

## Overview

This repository contains an ESP-IDF driver for Waveshare ST-series serial servos.

The implementation is based on the Waveshare Arduino/ESP32 driver approach and adapted for ESP-IDF.

## Compatibility

- Tested hardware: Waveshare ST3020 servo
- Target family: Waveshare ST-series serial servos (same protocol line)

## Software Environment

- Framework: ESP-IDF
- Version used for development and testing: 5.5.3

## References

- ST3020 servo documentation: https://www.waveshare.com/wiki/ST3020_Servo
- Waveshare ESP32 servo driver reference: http://www.waveshare.com/wiki/Servo_Driver_with_ESP32

## Notes

This project is intended to be protocol-compatible across the ST-series lineup, but validation may vary by specific model and firmware revision.
